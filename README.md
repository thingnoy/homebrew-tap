# homebrew-tap

Homebrew tap for [thingnoy](https://github.com/thingnoy)'s apps.

## Usage

```bash
brew install --cask thingnoy/tap/zen-markdown
```

Or add the tap first:

```bash
brew tap thingnoy/tap
brew install --cask zen-markdown
```

## Casks

| Cask | Description |
| --- | --- |
| [zen-markdown](Casks/zen-markdown.rb) | Fast, native markdown editor built with Rust + egui |
